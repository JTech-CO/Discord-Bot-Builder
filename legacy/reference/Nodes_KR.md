# Hybrid AI Bot Builder
## 각 계층별 필수 노드(블록) 10가지

---

### 1. 디스코드 인터페이스 계층 (Interaction Layer)

**핵심 역할:** 유저의 행동을 감지하고(Input), 결과를 시각적으로 보여주는(Output) 창구입니다.

| 순번 | 노드 명칭 | 타입 | 기능 설명 |
|------|----------|------|----------|
| 1 | **슬래시 커맨드 수신** | Trigger | `/명령어` 형태의 입력을 감지합니다. (옵션 값 입력 설정 포함) |
| 2 | **메시지 키워드 감지** | Trigger | 특정 단어나 문장(예: "안녕")이 포함된 메시지를 감지합니다. |
| 3 | **컴포넌트 상호작용** | Trigger | 버튼 클릭, 셀렉트 메뉴 선택, 모달 제출 이벤트를 감지합니다. |
| 4 | **멤버/서버 이벤트** | Trigger | 유저 입장/퇴장, 서버 부스트 시작 등 서버 상태 변화를 감지합니다. |
| 5 | **음성 채널 상태** | Trigger | 유저가 음성 채널에 접속, 퇴장, 마이크 음소거 등을 할 때 작동합니다. |
| 6 | **임베드(Embed) 전송** | Action | 제목, 설명, 이미지, 썸네일 등이 포함된 카드 형태의 메시지를 보냅니다. |
| 7 | **컴포넌트 부착** | Action | 메시지 아래에 **버튼**이나 **드롭다운 메뉴**를 생성하여 부착합니다. |
| 8 | **모달(Modal) 띄우기** | Action | 유저에게 팝업 입력창(설문조사, 신청서 등)을 띄워 입력을 받습니다. |
| 9 | **유저 권한 제어** | Action | 유저에게 역할을 부여/해제하거나, 타임아웃/킥/밴 처리를 수행합니다. |
| 10 | **스레드/채널 관리** | Action | 새로운 채널을 만들거나, 대화 주제별로 스레드를 생성/보관합니다. |

### 2. 기획 및 로직 계층 (System Logic Layer)

**핵심 역할:** 데이터를 가공하고, 저장하며, 흐름을 제어하는 봇의 논리 회로입니다.

| 순번 | 노드 명칭 | 타입 | 기능 설명 |
|------|----------|------|----------|
| 1 | **글로벌/유저 변수** | Data | 데이터를 저장/로드합니다. (예: `{user_gold}`, `{server_level}`) |
| 2 | **사칙연산 계산기** | Math | 변수 간의 더하기, 빼기, 곱하기, 나누기 및 나머지 연산을 수행합니다. |
| 3 | **랜덤/확률 생성** | Math | 주사위 굴리기, 난수 생성, n% 확률 성공/실패 여부를 판정합니다. |
| 4 | **조건 분기 (If/Else)** | Flow | 조건(A > B, 텍스트 일치 여부 등)에 따라 실행 흐름을 두 갈래로 나눕니다. |
| 5 | **다중 분기 (Switch)** | Flow | 하나의 변수 값에 따라 여러 갈래(케이스) 중 하나를 선택합니다. |
| 6 | **반복문 (Loop)** | Flow | 특정 횟수만큼 반복하거나, 리스트(목록)의 모든 항목에 대해 실행합니다. |
| 7 | **문자열 가공** | Logic | 텍스트를 합치거나, 특정 단어를 치환(Replace), 분리(Split)합니다. |
| 8 | **리스트(배열) 관리** | Logic | 아이템 목록에 값을 추가/삭제하거나, 랜덤으로 하나를 뽑습니다. |
| 9 | **타이머/대기** | Logic | 다음 블록 실행까지 일정 시간(초/분)을 대기합니다. |
| 10 | **날짜/시간 계산** | Logic | 현재 시간을 가져오거나, 특정 날짜까지 남은 시간(D-Day)을 계산합니다. |

### 3. 외부 연동 및 확장 계층 (Integration Layer)

**핵심 역할:** 외부 세계의 데이터를 가져오거나, AI 기능을 활용해 봇을 똑똑하게 만듭니다.

| 순번 | 노드 명칭 | 타입 | 기능 설명 |
|------|----------|------|----------|
| 1 | **HTTP 요청 (API)** | Network | 외부 API(날씨, 주식, 게임 전적 등)에 GET/POST 요청을 보냅니다. |
| 2 | **JSON 파서** | Network | API로 받아온 복잡한 데이터에서 원하는 값(예: 온도, 가격)만 추출합니다. |
| 3 | **웹훅(Webhook) 발송** | Network | 디스코드의 다른 채널이나 외부 서비스(슬랙, 잔디 등)로 알림을 보냅니다. |
| 4 | **LLM 프롬프트** | AI | ChatGPT/Claude 등에게 질문을 던지고 자연어 답변을 받아옵니다. |
| 5 | **AI 이미지 생성** | AI | 프롬프트를 입력받아 그림을 생성하여 URL로 반환합니다. |
| 6 | **스마트 크롤러** | AI | URL을 입력하면 뉴스 기사 본문, 상품 가격 등을 AI가 알아서 긁어옵니다. |
| 7 | **구글 시트 연동** | Ext | 구글 스프레드시트를 간이 데이터베이스처럼 사용하여 읽고 씁니다. |
| 8 | **번역 (Translate)** | Ext | 입력된 텍스트를 감지하여 다른 언어로 번역(DeepL/Google)합니다. |
| 9 | **STT / TTS** | AI | 음성 파일을 텍스트로 변환하거나, 텍스트를 음성 파일로 변환합니다. |
| 10 | **RSS 피드 리더** | Ext | 블로그나 뉴스 사이트의 새 글이 올라오면 감지하여 가져옵니다. |
